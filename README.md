# NeetCode Solutions — @CL-Buchan

Welcome. 
This repository contains my submissions for NeetCode problems, specifically the NeetCode-150 roadmap.

## The Purpose of the Repo

The purpose of this repository is to track my submissions for later reviews and personal improvements across my learning journey, to be come a more technical problem solver, gain more hands-on diversified exposure to such problems and to challenge myself as a aspiring developer.

---

## What is this?

[NeetCode.io](https://neetcode.io) is a coding interview preparation platform featuring curated problems, video solutions, and an in-browser code editor. This repository is automatically populated with your accepted (or all) solutions using the **GitHub Sync** feature.

---

## Repository structure

Solutions are organized by topic folder, then problem ID. Each submission is stored as a separate file:

```
<topic-folder>/
  <problem-id>/
    submission-0.<ext>   ← first submission
    submission-1.<ext>   ← second submission
    ...
```
